. Pourquoi eligible=false — ont-ils perdu leur stake ?
Non. Le stake est intact (0.005 ETH). Le problème c'est _judgeActiveTask[tokenId] — le contrat marque chaque juge comme "occupé sur une tâche". Tant que ce champ n'est pas vidé (par expireTask), le juge est bloqué même si son stake est là. C'est juste un flag interne, pas une question de stake.

Auto-expire = une boucle de fond dans le backend qui tourne toutes les 10 minutes et libère automatiquement les juges bloqués — sans avoir à lancer un script manuellement.

Le problème actuel :


Tâche bloquée en COMMITTING → judges "occupés" pour toujours
→ prochaine validation : NotEnoughEligibleJudges
→ tu dois manuellement lancer un script pour débloquer
Avec auto-expire :


Tâche bloquée en COMMITTING → 10 min plus tard la boucle détecte
→ appelle expireTask() automatiquement → judges libérés
→ prochaine validation : fonctionne normalement

Oui, tant que tous les juges partagent le même wallet, ce script sera utile à chaque fois qu'une validation échoue à mi-chemin.
